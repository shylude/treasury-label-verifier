# CompTIA Security+ (SY0-701) Prep

A personal study repository for the CompTIA Security+ exam. It is organized
around the five official exam domains, plus folders for hands-on labs and
practice-exam tracking.

## Target exam

- **Exam:** CompTIA Security+ SY0-701
- **Format:** Up to 90 questions (multiple choice + performance-based), 90 minutes
- **Passing score:** 750 on a scale of 100–900
- **My target date:** _TBD — set this in `study-plan.md`_

| # | Domain | Weight |

| 2 | [Threats, Vulnerabilities & Mitigations](02-threats-vulnerabilities-mitigations/) | 22% |

| 4 | [Security Operations](04-security-operations/) | 28% |
| 5 | [Program Management & Oversight](05-program-management-oversight/) | 20% |

## How this repo is used

- Each domain folder holds notes, key terms, and acronyms for that domain.
- `labs/` holds hands-on exercises (Wireshark, nmap, hashing, log analysis).
- `practice-exams/` tracks scores over time so weak areas are obvious.
- `study-plan.md` is the week-by-week schedule and progress checklist.
